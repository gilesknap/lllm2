{{ range $ingress.hosts }}

{{- else if eq $ingress.auth "external" }}

cannot check that: open the address in a private window and confirm that it
asks you to sign in before you use the panel.
{{- else }}

WARNING: ingress.auth is none. Anyone who reaches the addresses above
controls the workbench and can run any program in the pod.

{{- else if $exposed }}
The panel listens on the pod address and on the {{ $name }} Service, port
8082. It has no login or TLS, and anyone who reaches it can run programs in

{{- if and $exposed .Values.networkPolicy.enabled }}

8082, without signing in. To allow only the ingress controller or your
