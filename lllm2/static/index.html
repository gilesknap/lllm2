Context search processes a nearly full code prompt and generates the output budget. It reuses a successful full-window speed sample, then tests the ceiling and narrows the range as needed. It stops within roughly 10% of the largest success (at least 1,024 tokens), with at most 8 new probes, and saves failures. Long probes can take several minutes each. A timeout stops that configuration’s context search as inconclusive; it is not treated as a memory limit. Recommended context applies 10% headroom; it is an estimate, not a stability guarantee.
